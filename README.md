# Zen AI Chat Assistant

Zen is a sleek, modern, self-hosted AI chat assistant built for speed, privacy, and seamless extensibility.

## Features
- **Modern UI**: Clean, responsive interface designed for distraction-free conversations.
- **Self-Hosted**: Full control over your data and conversations.
- **Extensible Architecture**: Easily integrate custom models and backends.

## Prerequisites
- Node.js (v18+)
- npm or yarn

## Installation & Running
1. Clone the repository:
   \\\ash
   git clone https://github.com/Gifted87/zen-chat.git
   cd zen-chat
   \\\
2. Install dependencies:
   \\\ash
   npm install
   \\\
3. Start the application:
   \\\ash
   npm run dev
